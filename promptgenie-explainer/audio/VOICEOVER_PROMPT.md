## توجيه الأداء (ألصقه في خانة Style / Instructions أو قبل النص)

```
أدِّ النص بصوت معلّق إعلاني عربي فصيح، رجولي عميق ودافئ وواثق، بنبرة إعلانات الطراز الرفيع.
إيقاع سريع ومتصاعد الحماس: ابدأ بنبرة تساؤل فيها خيبة خفيفة في السطرين الأول والثاني،
ثم تحوّل إلى بهجة وثقة عند اسم المنتج، وأنهِ بدعوة حماسية حاسمة.
اترك وقفة قصيرة عند علامات (…) . انطق أسماء المنتجات كما هي: إيه آي بروبمت جيني، شات جي بي تي، كلود،
جيميناي، ميدجورني. بدون مبالغة مسرحية، ووضوح تام في مخارج الحروف. نهاية كل سطر قاطعة بلا تمطيط.
```

## أمر التوليد

### Higgsfield (الذي استُخدم هنا)
```
model:        seed_audio
voice_type:   preset
voice_id:     e2a2d2e6-9ed2-59cd-82af-feaa27f8a678   # Grady
format:       wav        sample_rate: 48000
speech_rate:  0 .. +10   # زِد قليلاً للسطرين 2 و7 فهما أطول من المتوقع
prompt:       <نص السطر من الجدول>
```
للجودة الأعلى جرّب `model: text2speech_v2` مع `variant: elevenlabs` (أو `elevenlabs_v4`) بنفس الصوت.
ولّد كل سطر منفصلاً، وسمِّ الملفات `01.wav` … `10.wav`.

### Google Cloud TTS أو ElevenLabs (من هذا المجلد)
```bash
GOOGLE_TTS_API_KEY=...  python3 audio/tts_premium.py google ar-XA-Chirp3-HD-Charon
ELEVENLABS_API_KEY=...  python3 audio/tts_premium.py elevenlabs <voice_id>
```

## بعد التوليد
```bash
python3 audio/import_vo.py <مجلد 01.wav … 10.wav>   # معالجة صوت المعلّق
python3 audio/fit_vo.py                              # ضبط المشاهد والترجمة والمؤثرات على المدد الجديدة
FFMPEG=/path/to/ffmpeg ./build.sh                    # الإخراج النهائي 1080×1920 / 60fps
```
