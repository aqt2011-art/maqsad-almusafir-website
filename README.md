# مؤسسة مقصد المسافر - Maqsad Al-Musafir

موقع رسمي لمؤسسة مقصد المسافر للسياحة الدينية والداخلية في المملكة العربية السعودية.

## 🌟 المميزات

- تصميم احترافي متجاوب
- نظام حجز ذكي للباقات
- نماذج تواصل متقدمة
- صور عالية الجودة
- تجربة مستخدم ممتازة

## 🚀 التقنيات المستخدمة

- React 19
- Vite
- Tailwind CSS
- Shadcn/UI
- Lucide Icons

## 📦 التثبيت والتشغيل

```bash
# تثبيت المكتبات
pnpm install

# تشغيل خادم التطوير
pnpm run dev

# بناء المشروع
pnpm run build
```
